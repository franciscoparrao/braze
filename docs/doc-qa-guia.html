Asistente de documentación local

Un chatbot que responde preguntas sobre tu documentación, corriendo 100 % en tu computador. Sin internet, sin cuentas, sin llaves de ningún servicio.

offline liviano sin GPU i7 basta

Qué hace: le das una carpeta con tu documentación (o tu banco de preguntas frecuentes), levanta una página de chat en tu navegador, y responde las preguntas de los usuarios usando solo tu documentación — citando de dónde sacó cada respuesta. Si algo no está en tus documentos, lo dice en vez de inventarlo.

Antes de empezar: por qué esto sí corre en tu máquina

No necesitas "la media máquina" ni una GPU. Este asistente hace una tarea simple de generación: busca el fragmento correcto de tu documentación y lo re-redacta. El trabajo pesado lo hace la búsqueda, no el modelo — por eso un modelo chico (qwen2.5:3b, ~2 GB de RAM) alcanza y sobra. En un i7 reciente sin GPU responde en unos pocos segundos.

Pasos

1

Instala Ollama y baja el modelo

Descarga Ollama de ollama.com e instálalo. Luego, en una terminal:

ollama pull qwen2.5:3b

Esto baja el modelo una sola vez (~2 GB). Queda en tu disco; después todo funciona sin internet.

2

Compila braze desde el código fuente

No hay un binario para descargar, y es a propósito: se compila del código, y así funciona igual en Windows, Mac o Linux (un binario compilado en otra máquina no te serviría). Francisco te pasará el código —un repositorio Git o un .zip—. Necesitas Rust instalado. Luego:

cd braze
cargo build --release -p braze-cli

El programa queda en target/release/braze (en Windows: target\release\braze.exe).

Con el backend Ollama no necesitas nada más: es Rust puro y compila sin complicaciones en Windows. (Existe un modo --backend local que mete el modelo dentro de braze sin Ollama, pero requiere compilar C++ y es engorroso en Windows; para empezar, usa Ollama.)

3

Prepara tu documentación como carpeta de Markdown

braze lee una carpeta con archivos .md. La clave para que responda bien: cada pregunta o tema es un título (##), y la respuesta va debajo.

# Proceso de Admisión

## ¿Hasta qué fecha puedo inscribirme a la PAES?

La inscripción regular comienza el 10 de junio; la fecha exacta de
cierre la publica el DEMRE en su calendario oficial cada año.

## ¿Qué puntaje se necesita para postular?

Se requiere 458 puntos promedio entre Comprensión Lectora y
Matemáticas 1. Cada carrera fija además su puntaje ponderado mínimo.

Si tu banco de preguntas está en un JSON (como el de admisión), este script lo convierte a Markdown por categoría:

python3 convertir.py preguntas.json ./mi-wiki
Ver convertir.py 
import json, sys, re, os, collections
data = json.load(open(sys.argv[1])); wiki = sys.argv[2]
os.makedirs(wiki, exist_ok=True)
def slug(s):
    s = re.sub(r'[^\w\s-]', '', s, flags=re.UNICODE).strip().lower()
    return re.sub(r'\s+', '-', s)[:60] or "cat"
# dedup: una entrada por pregunta, la respuesta más completa
best = {}
for e in data:
    q = re.sub(r'\s+', ' ', (e.get("question") or "").strip())
    a = (e.get("answer") or "").strip()
    if q and a and (q.lower() not in best or len(a) > len(best[q.lower()][1])):
        best[q.lower()] = (q, a, (e.get("category") or "General").strip())
by_cat = collections.defaultdict(list)
for q, a, cat in best.values():
    by_cat[cat].append((q, a))
for cat, qas in by_cat.items():
    with open(os.path.join(wiki, slug(cat) + ".md"), "w") as f:
        f.write(f"# {cat}\n\n")
        for q, a in qas:
            f.write(f"## {q}\n\n{a}\n\n")
print("listo:", sum(len(v) for v in by_cat.values()), "preguntas")

Ese script además deduplica: si una pregunta aparece repetida, se queda con la respuesta más completa. (Tu banco de admisión tenía 167 repetidas de 2331 — conviene limpiarlas.)

4

Levanta el asistente

./braze docs --serve --dir ./mi-wiki --backend ollama --model qwen2.5:3b

Verás algo como server en http://127.0.0.1:8080. Abre esa dirección en tu navegador y listo: ya tienes tu chat de documentación.

La primera pregunta puede tardar un poco (Ollama carga el modelo); de ahí en adelante queda caliente y responde rápido.

Cómo se usa

Escribe una pregunta como la haría un usuario ("¿qué becas hay?", "¿medicina tiene especialidades?"), presiona Enter, y el asistente responde con la información de tu documentación y muestra las fuentes abajo. Si no encuentra la respuesta, dice "No lo encuentro en la documentación" en vez de inventar.

Para responder una sola pregunta desde la terminal (sin abrir el navegador):

./braze docs --dir ./mi-wiki --backend ollama --model qwen2.5:3b "¿qué becas hay?"

Para que responda mejor

  • Títulos que suenen a la pregunta del usuario. El buscador matchea la pregunta contra los títulos ##. Mientras más se parezca el título a cómo preguntan las personas, mejor recupera.
  • Deduplica y evita respuestas contradictorias. Si dos secciones dicen cosas distintas para la misma pregunta, el asistente puede mezclarlas. Una respuesta clara por tema.
  • Preguntas específicas > vagas. "¿Cuánto cuesta la matrícula?" funciona mejor que "cuéntame del sistema": una pregunta con una palabra distintiva le da al buscador de dónde agarrarse.

Si algo no anda

SíntomaProbable causa
Dice "No lo encuentro" para algo que sí estáEl título de esa sección no se parece a cómo preguntaste, o la respuesta está en otra carpeta. Revisa el título.
Responde lentoLa primera pregunta carga el modelo. Si sigue lento, tu máquina está con poca RAM libre — cierra otras cosas.
